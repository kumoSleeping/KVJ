去掉了两台电脑之间的蓝牙互助，KVJ 只跟随本机听到的声音；声学追踪在相似段落和跳转后的速度上更稳；界面改成图标键，新增应用图标和详细日志。

## 去掉的功能
- 蓝牙发送端和「蓝牙接收」输入都已去掉。声学追踪只用本机的声卡、麦克风或系统声音（回环）。以前用蓝牙互助的，升级后在声学追踪里改选本机的输入。

## 声学追踪
- 同一条视频里有两处听起来一样的地方时，留在先出现的那一处，不再在两处之间来回跳；从别处跳过来时也落在先出现的那一处。
- 跳转后沿用跳转前的速度，也参考两次听到之间音乐走了多远，速度不再因为一次跳转偏到 0.93× 或 1.07×。
- 同一轨道上和别的条目声音相同的条目，会在素材库和时间线上标出来。
- 「监听」和「跟随」改成图标键，运行中也能换监听的轨道。
- 「关于 → 日志」里新增「详细日志」开关，打开后每一轮追踪都写进 `detail-<日期>.log`，方便排查。

## 画面和轨道
- 从单轨切回双轨时，另一条轨道回到保留的那条下面，正在播的画面不会再被盖住而像停住一样。
- 上屏和跳转共用一个「渐变」，最长 5 秒。暂停的轨道换画面时直接切，不做渐变。
- 暂停时，轨道的光标和播放头是同一个位置。
- 投屏、上屏、快切和声音改成图标键；声音键一按开关，旁边选播放哪一路。
- 「缩放同步」和「同步变速」改成放在所控制的键旁边的链接键。
- 系统不给的相机不会再让 KVJ 卡住。

## 其他
- 新的应用图标。
- 画板和输出预览的布局做了整理，画板的锁、撤回和确认键放在画面右下方。

## 下载
- macOS（Apple Silicon）：`KVJ-macos-arm64.dmg`。未经公证，首次打开请在「系统设置 → 隐私与安全性」中允许；捕获系统声音需要 macOS 14.2 或更高版本；每次更新后可能需要重新授予麦克风 / 相机等权限。
- Windows x64：`KVJ-windows-x64.zip`，解压后运行 `bin\KVJ.exe`，若提示缺少运行库，先运行同目录下的 `vc_redist.x64.exe`。未签名，SmartScreen 提示时选「仍要运行」。
- 每个安装包旁边附有 `.sha256` 校验文件。从 v0.2.2 起可以在「关于」里直接「下载并更新」。
