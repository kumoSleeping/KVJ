效果重新做了一遍：现在有 25 种，排成两列，nanoKONTROL2 的 8 个旋钮和 8 个推子各管一个效果。

## 效果
- 新增：反色、镜像、灵魂出窍、缩放冲击、抖动、漩涡、双色调、描边、高对比黑白、VHS、雨打玻璃、火焰、闪白、闪黑、频闪。水波和色调分离去掉了。
- 效果按固定顺序叠加：先布局和变形，再质感和调色，闪光最后，和效果键的位置无关。
- 闪白、闪黑和频闪的强度就是闪的速度，分 6 档，最快每秒 8 次。
- v0.4.0 的「跟着拍子」（旋钮选节奏、拍点上开关）去掉了，效果只按强度开着。

## 效果栏和 nanoKONTROL2
- 效果栏是两列。前八排对应控制器的八组：左边的键归旋钮，右边的键归推子；数字键 1–8 开关右列，Shift + 1–8 开关左列。其余效果排在下面。
- 默认排法（左 = 旋钮 / 右 = 推子）：
  1. VHS / 火焰
  2. 反色 / 雨打玻璃
  3. 色相 / 高对比黑白
  4. 双色调 / 鱼眼透镜
  5. RGB 分离 / 马赛克
  6. 黑白 / 多画面
  7. 故障 / 灵魂出窍
  8. 描边 / 抖动
- 想换位置：效果栏 ⋯ →「调整顺序」，把一个键拖到另一个上，两个就互换（也可以先按一个再按另一个）。下次打开还在；「顺序恢复默认」回到上面的排法。
- 旋钮和推子都只调强度，转动时不会让画面突然跳。
- 控制器上的按钮（S、M、R 三排、TRACK、MARKER、CYCLE 和走带键）全部用来发表情，共 35 个，新增 22 个动态表情。播放、跟随和投屏仍然不在控制器上。

## 声学追踪
- Set 里有素材的文件被删掉或移走时，开始跟随会把它从 Set 里移除，跟随照常进行，日志里写出它的路径。以前即使素材已禁用，也会整个失败，只报「os error 2」。
- 素材在没插上的外接盘（`/Volumes/…`）上时不会被移除，只是这次不参与跟随。

## 下载
- macOS（Apple Silicon）：`KVJ-macos-arm64.dmg`。未经公证，首次打开请在「系统设置 → 隐私与安全性」中允许；捕获系统声音需要 macOS 14.2 或更高版本；每次更新后可能需要重新授予麦克风 / 相机等权限。
- Windows x64：`KVJ-windows-x64.zip`，解压后运行 `bin\KVJ.exe`，若提示缺少运行库，先运行同目录下的 `vc_redist.x64.exe`。未签名，SmartScreen 提示时选「仍要运行」。
- 每个安装包旁边附有 `.sha256` 校验文件。从 v0.2.2 起可以在「关于」里直接「下载并更新」。
