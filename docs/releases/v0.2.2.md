修复 Windows 上 KVJ 最小化后再打开，中间的大画面停住、变黑、怎么跳转都恢复不了的问题；新增应用内更新。

## 画面
- 最小化时不再关掉视频，只暂停解码；窗口回来后从该播的位置接着放。
- 视频打开失败会自动重试；解码器 6 秒没有回应时换一个新的，画面不会再卡死。
- 视频的出错、恢复和更换解码器都会写进会话日志，方便排查。

## 应用内更新
- 「关于」里发现新版本时可以直接「下载并更新」：应用内下载、显示进度，核对大小和 SHA-256，退出后自动换成新版并重启。
- 正在跟随、发送或投影时不会自己重启，要手动点「中断并重启」。
- 新版 90 秒内没有正常启动，会自动回到旧版，并在「关于」里说明原因。
- 安装位置没有写权限（例如 Windows 装在 Program Files），或在 macOS 上没把 KVJ 拖进「应用程序」就直接运行时，仍然打开下载页。
- 这个功能从本版起才有：从 v0.2.1 及更早的版本升级到本版，还需要手动下载一次。

## 下载
- macOS（Apple Silicon）：`KVJ-macos-arm64.dmg`。未经公证，首次打开请在「系统设置 → 隐私与安全性」中允许；捕获系统声音需要 macOS 14.2 或更高版本；每次更新后可能需要重新授予麦克风 / 相机等权限。
- Windows x64：`KVJ-windows-x64.zip`，解压后运行 `bin\KVJ.exe`，若提示缺少运行库，先运行同目录下的 `vc_redist.x64.exe`。未签名，SmartScreen 提示时选「仍要运行」。
- 每个安装包旁边附有 `.sha256` 校验文件。
