GIF 贴图在画板和投屏上会一直动了；退出前总会先问一下，免得现场误按；「预备」的方块改成方角。

## 贴图
- GIF 和动态 WebP 按文件内容判断，不再看扩展名：从 QQ、微信存下来、扩展名是 `.png` 或 `.jpg` 的动图也会动。
- 文件里没写循环次数的 GIF 不再只播一遍就停在最后一帧，会一直循环。
- 动图有上限：画面不超过 1280×720 像素、不超过 3000 帧、文件不超过 48 MB。超过的只显示第一帧，坏文件不显示，原因写进日志；都不会让 KVJ 卡住。
- 读取贴图文件不再占用界面：文件在网络盘上、硬盘在休眠、或 macOS 正在询问访问权限时，界面照常响应，贴图读好之前先显示静帧。

## 退出
- 按 ⌘Q、Dock 里的「退出」、Alt+F4 或窗口的关闭键，都会先问「退出 KVJ？」，正在投屏或跟随时会说明退出的后果。窗口最小化时会先还原，让这个提示看得到。
- 电脑注销、重启、关机时不问，直接退出，不会拦住系统；应用内更新重启时也不问。

## 界面
- 「预备」里的方块全部改成方角，去掉了外面那圈框。在画面中的那块，边上画一道墨色线，里面衬一道细白线，深色画面上也看得出来。

## 下载
- macOS（Apple Silicon）：`KVJ-macos-arm64.dmg`。未经公证，首次打开请在「系统设置 → 隐私与安全性」中允许；捕获系统声音需要 macOS 14.2 或更高版本；每次更新后可能需要重新授予麦克风 / 相机等权限。
- Windows x64：`KVJ-windows-x64.zip`，解压后运行 `bin\KVJ.exe`，若提示缺少运行库，先运行同目录下的 `vc_redist.x64.exe`。未签名，SmartScreen 提示时选「仍要运行」。
- 每个安装包旁边附有 `.sha256` 校验文件。从 v0.2.2 起可以在「关于」里直接「下载并更新」。
