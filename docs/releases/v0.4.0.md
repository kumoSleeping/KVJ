效果可以用 Korg nanoKONTROL2 来调了：推子调强度，旋钮让效果跟着音乐的拍子动。

## nanoKONTROL2
- 先把它切到 CC 模式：拔下 USB，按住 SET MARKER 和 CYCLE 两个键插回去，再松开。设备会记住这个模式，只要做一次。效果栏底部的 ⋯ 键上有橙点，说明它还在 DAW 模式。
- macOS 上默认打开。Windows 上默认关闭，在效果栏的 ⋯ 菜单里选「使用 nanoKONTROL2」打开（Windows 版还没有在真机上试过）。KVJ 只打开名字里有 nanoKONTROL 的设备，同一台电脑上的 DJ 控制器不会动到画面。
- 八组推子、旋钮和按键对应效果栏从上往下的前八个效果，这八个键左边有一道竖线。想换成别的效果，在 ⋯ 菜单的「调整顺序」里把它拖进前八个。TRACK ▶ 切到第九个以后的效果，TRACK ◀ 切回来。
- 推子调效果的强度，推到底就是关。
- 旋钮设效果的节奏，共七档：不跟拍、2 小节、1 小节、2 拍、1 拍、1/2 拍、1/4 拍。
- S 键开关这个效果，和数字键一样。按住 M 键时效果反过来（开着的关掉，关着的按推荐强度打开），松开就恢复。R 键把节奏放回「不跟拍」。
- 走带键（播放、停止、录音等）、MARKER 和 CYCLE 都没有绑定，控制器不能播放、跟随或投屏。
- 推子和旋钮要先转到效果当前的值才接管，画面不会突然跳。用数字键、鼠标、调顺序或翻页之后，推子和效果强度对不上时，效果键底边有一个橙色小刻度标出推子的位置，把推子推过当前强度就接上了。还是「不跟拍」的效果，旋钮一转就生效。
- 拔掉控制器时，效果保持原样；插回去会自动认出来。

## 跟着拍子
- 会动的效果（RGB 分离、水波、故障、扫描线）每个周期把自己的动作走一遍。不动的效果每个周期开始时打开，到一半时关掉，在拍点上硬切。
- 拍子来自 KVJ 对视频声音的分析，和时间线上的 BPM 是同一套，现在把每一拍的位置也存了下来。跟随时对准 DJ 正在放的位置；没有跟随时对准画面 1 正在播的位置；两者都没有时，按最后听到的速度继续走，一开始是 120 BPM。
- 效果键右下角的小点按节奏闪，鼠标停在键上会显示节奏和当前 BPM。⋯ 菜单里的「节奏全部恢复不跟拍」可以一次全清掉。
- 小节从哪一拍开始是推测的，在长串混音里可能差一两拍；1 拍和更短的节奏不受影响。

## 其他
- 升级后，每个视频的速度分析会在后台重做一遍，为的是存下拍点。重做完之前，时间线上的 BPM 栏显示「分析速度…」。

## 后续计划
- 支持任意 MIDI 控制器和自定义按键绑定，像 djay 的 MIDI 学习那样。

## 下载
- macOS（Apple Silicon）：`KVJ-macos-arm64.dmg`。未经公证，首次打开请在「系统设置 → 隐私与安全性」中允许；捕获系统声音需要 macOS 14.2 或更高版本；每次更新后可能需要重新授予麦克风 / 相机等权限。
- Windows x64：`KVJ-windows-x64.zip`，解压后运行 `bin\KVJ.exe`，若提示缺少运行库，先运行同目录下的 `vc_redist.x64.exe`。未签名，SmartScreen 提示时选「仍要运行」。
- 每个安装包旁边附有 `.sha256` 校验文件。从 v0.2.2 起可以在「关于」里直接「下载并更新」。
