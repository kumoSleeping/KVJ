修复 Windows「自动」（WASAPI 回环）听得到声音却一直定位不到的问题；蓝牙发送端同样受影响，一并修复。

## Windows
- 回环采集时，同一渲染周期里的音频包带着相同的时间戳，KVJ 以前把它们当成时间跳变，每个包都重来，识别窗口永远攒不满。现在按采样数走时间线，时间戳只做微调，偏差超过 50 ms 才算断流。
- 日志的「采集时间线」一行新增「包时间偏差」，方便判断声卡的时间戳是否正常。

## 蓝牙
- 发送端用的是同一份采集代码，用回环发送时也会一直重来；现在随上面的修复一起恢复正常。

## 下载
- macOS（Apple Silicon）：`KVJ-macos-arm64.dmg`。未经公证，首次打开请在「系统设置 → 隐私与安全性」中允许；捕获系统声音需要 macOS 14.2 或更高版本；每次更新后可能需要重新授予麦克风 / 相机等权限。
- Windows x64：`KVJ-windows-x64.zip`，解压后运行 `bin\KVJ.exe`，若提示缺少运行库，先运行同目录下的 `vc_redist.x64.exe`。未签名，SmartScreen 提示时选「仍要运行」。

完整说明见 [README](https://github.com/kumoSleeping/KVJ#readme)。
